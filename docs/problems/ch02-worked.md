## Lecture Problems

### [Lecture] Path 2 — position after 45.0 min

**Asked:** position $x$ at $t = 45.0$ min after leaving Anderson

**Given:** $x_0 = +19.0$ mi, $v = +50.0$ mi/hr (constant), $t = 45.0$ min

**Missing/not needed:** acceleration — velocity is constant, so $a = 0$

**Equation + why:** $x = x_0 + vt$ — constant velocity, no acceleration term needed

**Work:**

Convert time first:

$$45.0\ \text{min}\left(\frac{1\ \text{hr}}{60\ \text{min}}\right) = 0.750\ \text{hr}$$

$$x = +19.0\ \text{mi} + (+50.0\ \text{mi/hr})(0.750\ \text{hr})$$

**Answer:** $x = +56.5$ mi

**Checks:** units (mi) ☑ · sign: positive, consistent with driving north ☑ · magnitude: reasonable, lands near the Gaffney side of Barton ☑

📌 *Board value read +56.0 mi — worth double-checking against the original problem statement.*

### [Lecture] Motion table — car accelerating from +5.00 m/s

**Asked:** velocity and position at $t = 2.00, 4.00, 6.00$ s

**Given:** $x_0 = 0$ m, $v_0 = +5.00$ m/s, constant $a = +4.47$ m/s²

**Missing/not needed:** nothing missing — every variable given except the two being solved for

**Equation + why:** $v = v_0 + at$ for velocity; $x = x_0 + v_0t + \tfrac{1}{2}at^2$ for position — both are the direct constant-$a$ formulas

**Work (shown at $t = 2.00$ s):**

$$v = (+5.00) + (4.47)(2.00) = 13.94\ \text{m/s}$$

$$x = 0 + (5.00)(2.00) + \tfrac{1}{2}(4.47)(2.00)^2 = 10.0 + 8.94 = 18.94\ \text{m}$$

| $t$ (s) | $v$ (m/s) | $x$ (m) |
|---|---|---|
| 0 | +5.00 | 0 |
| 2.00 | +13.94 | 18.94 |
| 4.00 | +22.88 | 55.76 |
| 6.00 | +31.80 | 110.5 |

**Answer:** table above — at 6.00 s the car reaches +31.80 m/s (≈60 mph) and has traveled 110.5 m

**Checks:** units ☑ · signs all positive, consistent with speeding up in the + direction ☑ · magnitude: 0–60 in 6 seconds is a fast car, but plausible ☑

### [Lecture] Crash test — no time given

**Asked:** acceleration $a$

**Given:** $v_0 = +18.0$ m/s, $v = 0$ m/s, $x - x_0 = 1.20$ m

**Missing/not needed:** $t$ — never given, never asked for

**Equation + why:** $v^2 = v_0^2 + 2a(x - x_0)$ — it's the only kinematic equation with no $t$ in it

**Work:**

$$a = \frac{v^2 - v_0^2}{2(x - x_0)} = \frac{(0)^2 - (18.0)^2}{2(1.20)} = \frac{-324}{2.40}$$

**Answer:** $a = -135$ m/s²

**Checks:** units $\frac{\text{m}^2/\text{s}^2}{\text{m}} = \text{m/s}^2$ ☑ · sign: $v$ is +, $a$ is − → slowing down ☑ · magnitude: ≈14 g, brutal but that's a wall ☑
