## Example — fully worked

### [Lecture] Crash test

**Asked:** acceleration $a$

**Given:** $v_0 = +18.0$ m/s, $v = 0$ m/s, $x - x_0 = 1.20$ m

**Missing/not needed:** $t$ — never given, never asked for

**Equation + why:** $v^2 = v_0^2 + 2a(x - x_0)$ — it's the only kinematic equation with no $t$ in it

**Work:**

$$a = \frac{v^2 - v_0^2}{2(x - x_0)} = \frac{(0)^2 - (18.0)^2}{2(1.20)} = \frac{-324}{2.40}$$

**Answer:** $a = -135$ m/s²

**Checks:** units $\frac{\text{m}^2/\text{s}^2}{\text{m}} = \text{m/s}^2$ ☑ · sign: $v$ is +, $a$ is − → slowing down ☑ · magnitude: ≈14 g, brutal but that's a wall ☑
