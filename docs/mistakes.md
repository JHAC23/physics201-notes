# Mistake Log

**The most valuable file in this repo.** Every problem you get wrong goes here — homework, quiz, exam, practice, doesn't matter.

## Why this works

By the time finals come around, you won't have a vague sense of "I'm bad at kinematics." You'll have a specific, short, repeating list of *your* failure modes. Most students discover they make the same 4–6 errors over and over. Once you can name them, you can catch them mid-problem.

## How to log one

Keep it to one row. If it takes more than 30 seconds, you're writing too much.

- **What I did** — the wrong move, in a few words
- **What was right** — the correction
- **Trigger** — what in the problem *should* have tipped you off

Then tag it so you can count them later.

## Tags

Use these so you can scan for repeats. Add your own as patterns show up.

| Tag | Meaning |
|---|---|
| `#sign` | dropped or flipped a sign / direction |
| `#units` | didn't convert (min→hr, km→m) or unit mismatch |
| `#eq` | picked the wrong kinematic equation |
| `#dist-disp` | confused distance with displacement (or speed with velocity) |
| `#assume` | assumed constant acceleration when it wasn't |
| `#algebra` | setup was right, arithmetic wasn't |
| `#read` | misread what the problem was asking for |
