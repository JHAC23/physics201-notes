Position vs. Time

slope of this curve = velocity

Velocity vs. Time

slope = acceleration · shaded area = displacement

At the time cursor

velocity — v = v₀ + at
position — x = x₀ + v₀t + ½at²
displacement — Δx = x − x₀
Things worth trying. Set a = 0 and watch x-vs-t go perfectly straight — that's constant velocity. Then set v₀ positive and a negative and watch the object slow, stop, and reverse: the v-vs-t line crosses zero exactly at the turning point, and the shaded area starts cancelling itself out. That cancellation is the reason distance and displacement stop matching.
